# Reference system

A neutral multi-controller system used as the walkthrough and the subject of milestone exit criteria ([ADR-0004](../../docs/adr/0004-reference-system.md)). Three controllers interact only through Kubernetes resources in the `refsystem.example.org` group:

| Kind | Spec | Status | Owned by |
| --- | --- | --- | --- |
| `Tenant` | `quota` | `namespaceReady` | tenant controller |
| `Database` | `tenant`, `size` | `ready`, `secretName` | database controller |
| `Backup` | `database` | `phase` | backup controller |

- `api/v1alpha1/`: Go types, scheme registration and generated deepcopy methods.
- `config/crd/`: CRD manifests generated by `make api-generate`.
- `controllers/`: the three controllers and their fake-client tests.
- `internal/extractcheck/`: runs the extractor over one controller package; each controller test uses it to prove that the controller extracts with no diagnostic.

## Controllers

| Controller | Creates | Watches | Requeue |
| --- | --- | --- | --- |
| tenant | a `Namespace` named after the Tenant, and a `ResourceQuota` in it with a hard limit of 10 pods | `Tenant` | none |
| database | a `Secret` named after the Database, beside it | `Database`, owned `Secret`, `Tenant` through the Databases labelled with its name | none |
| backup | a `Job` named after the Backup, beside it | `Backup`, owned `Job`, `Database` through the Backups whose `spec.database` names it | 30 seconds while the Job runs |

## Owner references

Kubernetes accepts an owner reference only when the owner is cluster-scoped
or lives in the same namespace as the dependent. The controllers follow that
rule:

- The tenant `Namespace` has no owner. A Namespace is cluster-scoped and a
  Tenant is namespaced, so the Tenant cannot own it. For the same reason the
  tenant controller has no owner watch: no event on the Namespace would map
  back to the Tenant.
- The `ResourceQuota` lives in the tenant namespace, not beside the Tenant.
  The Namespace owns it, through `controllerutil.SetOwnerReference`.
- The `Secret` lives beside its Database, which controls it through
  `controllerutil.SetControllerReference`.
- The `Job` lives beside its Backup, which controls it through
  `controllerutil.SetControllerReference`.

## Known extractor gap

The Secret has the Database's name. A name such as
`database.Name + "-credentials"` reads better, but the extractor cannot yet
lower a string concatenation with a field. The controller keeps the bare
name until it can.

The project document and Flux boundary model are added by later milestone issues.
